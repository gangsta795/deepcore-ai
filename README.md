# DeepCore AI

### Building Specialized Artificial Intelligence

DeepCore AI is an AI research and development project focused on adapting existing Large Language Models (LLMs) for specialized tasks and delivering them through developer-friendly APIs.

## 🎯 Our Mission

To make specialized artificial intelligence accessible, reliable, and affordable for software developers.

## 🚀 Our First Product

**DeepCore Code AI**

A specialized AI model focused on:

- Python debugging and error analysis
- Code explanations
- Code review
- Programming assistance
- Automated test-case generation

## 🧠 Technology Stack

- Python
- Hugging Face
- Ollama
- PyTorch
- PEFT / LoRA
- FastAPI

## 🗺️ Development Roadmap

 Research existing coding LLMs
 Select a suitable base model
 Build a curated programming dataset
 Experiment with model fine-tuning
 Evaluate model performance
 Develop the API
 Deploy the first public beta

## 🌎 Vision

Build a collection of specialized AI models that developers can access through simple and powerful APIs.
